## 🔑 Ключевые концепции для контрольной

### Наследование
```cpp
class Derived : public Base {
    // Производный класс наследует от базового
};
```

### Конструктор с инициализацией базового класса
```cpp
Derived() : Base(параметры) {
    // тело конструктора
}
```

### Список инициализации
```cpp
MyClass(int x, string s) : field1(x), field2(s) {
    // Инициализация полей через список
}
```

### Модификаторы доступа
- `public` - доступно всем
- `protected` - доступно в классе и наследниках
- `private` - только внутри класса

### Переопределение методов
```cpp
class Base {
    virtual void method() { ... }
};

class Derived : public Base {
    void method() override { ... }  // Переопределение
};
```

## 📖 Часто задаваемые вопросы

**В чем разница между struct и class?**
- В struct по умолчанию все `public`
- В class по умолчанию все `private`
- В остальном они идентичны

**Зачем нужен список инициализации?**
- Это правильный и эффективный способ инициализации полей
- Особенно важен для констант и ссылок
- Обязателен для вызова конструктора базового класса с параметрами

**Что такое protected?**
- Промежуточный уровень доступа
- Доступен в самом классе и всех наследниках
- Недоступен извне класса

**Когда метод нужно делать virtual?**
- Когда хочешь динамический полиморфизм
- Когда вызов метода должен зависеть от реального типа объекта
- В нашем базовом примере virtual не используется
